
# puzzle-cat-js-game

- A multiplayer jigsaw puzzle game
- Players upload an image
- Image is split into puzzle pieces
- Pieces appear in a shuffled pile
- Players drag pieces into the board
- Scores are tracked
- Data persists with Local Storage
